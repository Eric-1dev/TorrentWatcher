# Фикстуры

`rutracker-multifile.torrent` — реальный `.torrent`, скачанный с рутрекера (9 файлов).
В `announce` и `announce-list` личный passkey заменён нулями той же длины: размеры bencode-строк
не изменились, поэтому infohash и остальные поля остались исходными.

Остальные фикстуры собираются кодом в `Domain/Parsing/TorrentFixtures.cs`, чтобы не хранить
в репозитории лишние бинарные файлы.
